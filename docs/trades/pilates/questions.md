# Reformer Pilates studios: customer questions

What this trade's customers ask before they get in touch (kit `pilates`). How to read it and the questions every trade gets: [`docs/CUSTOMER-QUESTIONS.md`](../../CUSTOMER-QUESTIONS.md).

## Luxury reformer Pilates studio (pilates kit, branch `trade/pilates`)
Researched 29 Oct 2026 from real studios' pages and press (Nobu Pilates at Nobu Hotel Portman Square, Pilates in the
Clouds in Notting Hill and Harvey Nichols, BLOK Shoreditch, Studio Anatomy in London Fields, SheerLuxe's London round-up)
and a first-timers' question list. Every class, price, policy and date on a client site comes from the client.

| Customers ask | What answers it |
|---|---|
| I've never done reformer. Which class first? Is there an induction? | `first-class` (the class to book, then the steps); `class-finder` (Plus) |
| What's on today, and is there a place? | `timetable` (next classes in the hero, the week below); `spaces-left` (Plus) draws the room's reformers |
| A class is full. Can I get on a list? | `waitlist` (Plus): a WhatsApp message naming the class, day and time |
| How many people are in a class? | the reformer marks (the room's size) and a question in Plan your visit |
| What does a class cost? Packs? Is there an intro offer? | `intro-card` (Plus) with the studio's own price and Stripe link; packs in the questions |
| What do I wear? Grip socks? Can I buy them there? | `first-class` steps and the questions |
| Can I come pregnant, or after a baby? With an injury? | class types (pre and postnatal, in the studio's words); the questions; a private session first |
| What's the cancellation window, and what if I'm late? | the questions, in the studio's words |
| Showers, towels, lockers? | the questions |
| Private sessions? Duets? An assessment first? | `private-page` (Signature): kinds, the assessment, a request on WhatsApp |
| Retreats: where, when, what's included, how do I hold a place? | `retreats-page` (Signature): dates, inclusions, deposit link, Google Form list |
| Can I give a class as a present? | `gift-cards` (Plus) and `vouchers` |
| Can I put my classes in my calendar? | `your-week` (Plus): ticked classes as one .ics at the studio's time |
| Who teaches? | `team` (Plus) |
| Where are you, nearest station, parking, step-free? | Plan your visit |
| Which pack or membership works out cheapest for me? | `pack-calculator` (Plus) |
| What will I actually do in a class? | `class-pages` and `method-library` (Signature) |
| How many classes have I got left, and when do they run out? | `class-passport` (Signature), by code |
| What were my springs again? | `reformer-settings` (Signature): the teacher's link |
| Can we hire the studio, or book team classes? | `private-hire` (Signature) |
| Do you run workshops? | `workshops` (Signature) |

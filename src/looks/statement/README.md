# Statement (kit: ifa)

A private bank's statement for an independent financial adviser. A holly-green header band with a round seal and the
firm's name in spaced capitals; one wide photograph of the street; the fees, in pounds, as a statement card overlapping
it (`ifa-statement`, with this look's seal in `features/ifa-statement/mark.njk`); ruled tables after. Frank Ruhl Libre
throughout (300/400/500, self-hosted, size-matched fallback). The footer carries the status line with the FRN linked to
the register, the company, the Financial Ombudsman's free number and the ScamSmart check on every page.

Hero data: `hero.title` (ten words at most), `hero.intro`, `hero.photo` (wide, with `credit`), `hero.photoTall` (phone).
Brand: the client's colour replaces holly green (`look.json` suggests five deep inks that keep white text readable).

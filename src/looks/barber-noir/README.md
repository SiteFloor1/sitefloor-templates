# Look: Barber Noir

Dark gentleman's club. Used by the barber kit.

| | |
|---|---|
| Colours | near-black `#0F0D0C`, warm gold `#C9A46A`, cream text `#F5EFE6` |
| Fonts | Playfair Display (headlines, self-hosted), Manrope (body, self-hosted) |
| Buttons | square gold blocks with a soft gold glow |
| Edges | hard corners, deep shadows |
| Signature | pure-CSS spinning barber pole in the hero |

Files: `look.css` (tokens + look-only styling), `fonts.css`, `hero.njk`.

**Rule:** a new look must be visually unrecognisable next to every existing look:
different palette, type pairing, button shape, edge treatment and hero idea.

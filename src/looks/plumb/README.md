# Plumb (cleaning kit)

Home and office cleaning, precise and technical. Approved 15 Nov 2026 (`sitefloor-internal/docs/design/cleaning.md`, round 4).

| | |
|---|---|
| Ground | white; pale steel panels (`--surface`) for working areas; ink footer |
| Accent | kingfisher blue `#0A6F98` (from a kingfisher's back): the room strip, links and the one filled button |
| Type | Anek Latin only: 800 for the headline and figures, 600 for labels, 400 for text; tabular figures |
| Emblem | a set square drawn in a single stroke (`header.njk`, `favicon.svg`) |
| Hero | a wide photograph of a just-cleaned room, the two-line headline, one line saying what the strip is, then the room strip: each room as wide as its minutes over a minute ruler, with the controls beside it. At 1440 × 900 all of it fits the first screen; on phones the strip runs downward |
| Header | emblem and name, the pages by plain names, "Get a price" (to the bill); a Menu sheet on phones |
| Phone bar | WhatsApp and Get a price |
| Photography | bright daylight, white rooms, one cool grade towards the accent |
| Motion | the strip's rooms resize when the home changes (0.7 s); nothing tied to the scroll |

Home order: the room strip (in the hero), the bill, the key log, what we clean, reviews (clients only), where we
clean, questions, page links, the office.

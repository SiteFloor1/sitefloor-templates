# Verrière (fragrance kit)

A perfume house's still life. One bottle, large, in a warm studio on travertine; on Signature the visitor turns it by
dragging (the house's turntable frames), and its notes are one sentence set across the glass. The name at the top
left, the sizes and Buy in one row under the plinth; then the engraving desk, half picture, half form. Warm stone
ground, ink, the perfume's pale champagne gold. Hina Mincho and SUSE, sentence case throughout.

- `site.hero`: `kicker` (the house in a line, used in the page title), `fragrance` (the id the hero shows), `photo`
  (the hero picture; with the turntable on, its frame 1), `phonePhoto?` (an upright crop), `marks` (where the bottle
  sits on the picture, fractions: `neck`, `shoulder`, `base`, `xl`, `xr`, `floor`; needed for the notes), `credit?`.
- The stage takes the picture's own shape on desktop, so the marks place the name, notes and Buy without script.
- Accent: any of the suggested colours, or the house's own if it passes contrast on the stone ground.

# route-cards (Signature, needs club-page)
Each run with a `route` on the club page gets its route card: the route drawn from `club.routes[].points` (the club's own
GPX points, `[lat, lng, metres?]`, north up, true shape), the distance and climb worked out from those points (no climb
is claimed without elevations), and "Save as a picture" (1080×1350, the look's colours and fonts; share sheet or download).

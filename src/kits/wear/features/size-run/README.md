# size-run (Signature)
Every size of every piece with a count and a bar emptying from that piece's fullest size; the drop's pieces first. From
the same stock sheet as the pieces; hidden (not stale) when the sheet can't be read or is older than `stock.staleAfterHours`.
On drop day it's the picture people screenshot. Also shown on the drops page when on. Section copy: `sections.sizeRun`.

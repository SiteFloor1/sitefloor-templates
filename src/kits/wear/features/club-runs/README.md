# club-runs (Starter)
The run club on the home page: one wide photograph of the club, then the week's runs in columns, each with "I'm in" on WhatsApp.

- `club.runs[]`: `{ id, day, time, minutes, title, text, meet, route? }` on the brand's clock.
- `club.rsvp`: the WhatsApp message; `{run}` becomes "Park laps, Thursday, 7pm".
- `club.photo` (wide) and `club.photoTall` (phones).

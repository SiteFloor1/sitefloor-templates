# details (Starter)
"In detail": two to six of the brand's own close-ups (zip, seam, cuff, rain on the cloth), very large, each with one short line.

- `details.items[]`: `{ photo: { src, width, height, alt }, line }`.
- Lines say what the photo shows; never a performance claim the brand can't show from the mill's spec.
- Replaces a made-in film for brands without good footage; stills of the brand's own work read better than stock film.

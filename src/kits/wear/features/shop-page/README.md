# shop-page (Plus) → `shells.html`
One piece per row: two photographs large, kind, name and colour, its line, the price, the stock words and every size
marked in, few or out from the brand's sheet. Buy opens the piece on the brand's own shop (`pieces[].buy`, else `shop.url`);
on a demo it says so instead of leaving the site. Copy: `shellsPage { kicker, title, intro, description }`.

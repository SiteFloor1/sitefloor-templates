# Ofsted and policies

| | |
|---|---|
| Feature id | `nursery-ofsted` |
| Plan | plus and above |
| Config | `ofsted`: `outcome` (in the report's own words), `inspected` (YYYY-MM-DD), `reportUrl` (on reports.ofsted.gov.uk), `urn?`, `text?`, `policies?` (`{ label, text }`); `ofstedPage` |
| Files | `nursery-ofsted.njk`, `nursery-ofsted.css` |

## Rules
Only what the nursery supplies, in the report's own words, with the inspection date and the report linked on Ofsted's
own site (the checks refuse any other address). No badge or grade is drawn by us, and nothing goes in structured data.

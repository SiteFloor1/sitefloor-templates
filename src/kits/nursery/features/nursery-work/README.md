# The work

| | |
|---|---|
| Feature id | `nursery-work` |
| Plan | signature |
| Config | `work`: `items` (2 to 40 pieces, each `{ photo, title, room, area, text? }`), `note?`; `workPage` |
| Files | `nursery-work.njk`, `nursery-work.css` (the caption card's base is in `nursery-wall.css`) |

## Rules
Children are never identifiable: no faces; no names or initials on the work (crop or blur before the photo goes in).
Captions are the nursery's own words; `area` is one of the seven EYFS areas of learning.

# The wedding morning

| | |
|---|---|
| Feature id | `bridalbeauty-morning` |
| Plan | signature |
| Config | `morning` (see `bridalbeauty-start`), `morningPage`: `{ title, intro }`; uses `packages` and `party.start` |

Her date, the ceremony time, her service and her party in; out comes everyone's slot in the chair (worked back from the
ceremony with the artist's minutes), the start time, when dresses go on and when to leave. A second artist joins when
one alone would start before `morning.secondArtist.earliest`, and the chairs are shared between two. "Add to calendar"
writes each slot at its local time on her wedding day; "Send to your group" opens WhatsApp with the whole morning for
her to forward; "Send this morning to …" asks the artist to hold it (never booked).

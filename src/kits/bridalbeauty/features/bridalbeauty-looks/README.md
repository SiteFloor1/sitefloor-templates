# The look library

| | |
|---|---|
| Feature id | `bridalbeauty-looks` |
| Plan | plus |
| Config | `looks`: `{ message, season: [4 ids], items: [{ id, name, finish, hair, minutes, text?, photo }] }`; `looksPage`: `{ kicker, title, intro }`; home heading in `sections.season` |

The artist's own brides (with their consent), each look named for its makeup and hair the way she'd say it ("Satin,
half up"), filed under a finish (natural, soft glam, full glam, editorial) and a hair (up, half up, down, sleek, under a
veil, hijab styling). Four sit on the home page as This season (`season`); every look is on its page, found by finish
or hair. "Ask for this look" writes her a WhatsApp message naming the look. Photos are the artist's own work, one bride
per photo; no before and after.

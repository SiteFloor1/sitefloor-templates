# designers (bridal kit, Starter)

The houses the salon stocks: name, what each is known for, and its price band in the salon's own words. With the
gowns page (Plus) each links to its gowns, already filtered (`gowns.html#<id>`).

```json
"designers": { "items": [{ "id": "studio-morrell", "name": "Studio Morrell", "known": "Silk mikado, structured and quiet", "prices": "£5,200 to £6,400" }] }
```
Heading: `sections.designers`. Real designers' names appear only on a client's site, as the salon stocks them.

# brides-page (bridal kit, Plus)

`brides.html`: what brides say (`reviews`, set by the look as quotes) and the salon's latest photographs (`gallery`),
moved off the home page by the look (`look.json` → `onPages`), so the home page stays to a few quiet sections.

```json
"bridesPage": { "kicker": "Brides", "title": "In their words", "intro": "…" }
```
Reviews on a client site are real, copied from Google with name and date.

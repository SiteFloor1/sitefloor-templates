# tourism-atol (Starter)

The ATOL number (TOUR-2): a home section and a line in the footer of every page, showing `atol.number` exactly as the
operator's ATOL certificate gives it. We never format, check or explain it: the operator's own words go in `note`, and
`termsUrl` links their booking terms (an https link, or a page of this site such as `/terms`).

```json
"atol": { "number": "ATOL 12345", "holder": "Protected by …", "note": "…", "termsUrl": "/terms" }
```

Heading: `sections.atol`.

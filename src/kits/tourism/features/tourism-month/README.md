# tourism-month (Signature)

The journey of the month, in the home page's hero: it opens on the operator's pick for this month
(`journeys.monthly`, months 1–12 to journey ids) with "Journey of the month · November" above it; any other journey
says "From the logbook", so nothing is called "of the month" that isn't. Beneath, four journeys as a quiet index (name,
where, nights, best months; this month's first): choose one and its logbook (photograph, words, stops and map) shows
in place. No carousel, no autoplay; the rest of the journeys are reached from the year drawn and the journeys list.

The build draws the build day's month; the browser opens the real month's pick on load. A month with no pick opens
`hero.journey` (or the first journey) as "From the logbook".

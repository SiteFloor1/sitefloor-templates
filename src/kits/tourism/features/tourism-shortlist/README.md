# tourism-shortlist (Plus)

Keep journeys while reading (on the home page's journeys and on each journey page), then send the list to the operator
as one WhatsApp message: "these are the journeys we like: · Desert to ice (11 nights) … Could we talk about dates?".
Kept in this browser only (`localStorage`, and only for this visit if the browser refuses); nothing is sent until they
tap Send. Clear empties it. No settings.

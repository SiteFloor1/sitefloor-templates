# tourism-finder (Plus)

The year, drawn (TOUR-3), a home section. Each journey is a row of twelve months: a solid line for the months the
operator would go (`go`), dashed for the rest. Choose a month (it opens on this one), who's going (two of us, family,
friends, just me: `who`) and roughly how long (a week, ten days, two weeks: within three nights of `nights`). The
journeys that fit move to the top in the operator's order and the rest fade back; a line counts them, or says plainly
that nothing fits. One plain line above the rows explains the drawing: "The solid line is when we'd go."

No sentence to fill in, no scores: it only uses the operator's own months, who it suits and nights.
Heading: `sections.finder`.

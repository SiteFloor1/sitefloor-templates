# tourism-when (Plus)

When to go (TOUR-4), a page (`when-to-go.html`): the operator's places as rows, the months across, the months they'd
choose underlined; a place can open its journey. With `tourism-weather` on, each cell shows that month's typical
daytime high from `climate`, and the caption names the source and period ("not a forecast").

```json
"when": { "title": "When to go", "intro": "…", "places": [{ "name": "Torres del Paine", "go": [1, 2, 3, 11, 12], "journey": "desert-to-ice", "climate": "natales" }] }
```

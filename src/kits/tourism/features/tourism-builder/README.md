# tourism-builder (Signature)

The trip builder (TOUR-6), a page (`plan.html`): the operator's regions, each with the fewest and most nights they
suggest there. "+" adds a region at its fewest nights, then a night at a time up to the most; "−" takes nights off
and removes it below the fewest. With a month (or "not sure yet") and who's going, the total and the list go to the
operator as one WhatsApp message. Never a price: the operator replies with a route and a quote.

```json
"builder": { "title": "Plan a journey", "intro": "…", "regions": [{ "id": "atacama", "name": "The Atacama", "where": "Chile", "nights": [3, 5], "line": "…" }] }
```

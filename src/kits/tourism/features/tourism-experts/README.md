# tourism-experts (Plus)

Who's been there, a page (`experts.html`): each of the operator's travel experts with their role, a line in their own
words, the places they've travelled and, if they want it, their direct line; then every place with who has been.

```json
"experts": { "title": "Who's been there", "intro": "…", "people": [{ "name": "…", "role": "…", "line": "…", "been": ["Chile", "Namibia"], "phone": "+44 …" }] }
```

Names are the operator's staff, with their agreement. No photographs of people by default.

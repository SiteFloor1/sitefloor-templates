# Flavours page

| | |
|---|---|
| Feature id | `flavours-page` |
| Config | `cakePages.flavours` (`title`, optional `intro`), `flavours` |
| Files | `flavours-page.njk`, `flavours-page.css`; the page is `src/kits/cakes/pages/` |

The flavours page: every flavour with what's in it, when it's on and its allergens, then the flavour calendar. The look decides which home sections move here (look.json `onPages`, allowed in `src/kits/cakes/home.js`).

# How a commission works

| | |
|---|---|
| Feature id | `how-it-works` |
| Plan | signature |
| Config | `process.steps[]` (`title`, `text`, in order: at least two), optional `process.terms` (the studio's deposit, balance and cancellation terms, or where to read them); `sections.process` |

The steps are numbered because they happen in that order. Every term is the studio's own.

# Caring for your cake page

| | |
|---|---|
| Feature id | `cake-care-page` |
| Config | `cakePages.care` (`title`, optional `intro`) |
| Files | `cake-care-page.njk`, `cake-care-page.css`; the page is `src/kits/cakes/pages/` |

A page for looking after the cake, to send with every order; it hosts the care card. The look decides which home sections move here (look.json `onPages`, allowed in `src/kits/cakes/home.js`).

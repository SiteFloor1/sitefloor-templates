# Commissions (a page for each cake)

| | |
|---|---|
| Feature id | `commission-pages` (pages `commissions` and `commission-<id>`; a generated collection, so it counts as one page) |
| Plan | signature (needs `commissions`) |
| Config | `pieces.items` (see `commissions`); `cakePages.commissions` |
| Files | `commission-pages.njk` (all of them), `piece.njk` (one), `commission-pages.css` |

Every cake on one page, and a page for each: the photograph large beside its label (number, name, how it's made,
tiers, servings, flavours, "from") and "Commission one like it", a WhatsApp message naming the cake.

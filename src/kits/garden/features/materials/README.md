## How it works
The stone, brick, gravel, timber and steel the studio builds with, as large photographs on one board in six repeating
sizes, each with a tag. Touch (or hover) a sample and it crossfades into the garden it was laid in, named on the tag;
that garden's photograph loads only then. Tick "Ask for a sample" on any of them and the WhatsApp message lists them.
Without JavaScript the tags and the gardens' names show.

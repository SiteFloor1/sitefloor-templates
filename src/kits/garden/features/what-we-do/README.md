| | |
|---|---|
| Feature id | `what-we-do` |
| Plan | starter and above |
| Config | `whatWeDo.items`: `id` (`design`, `build` or `care`), `name`, `text` (one sentence); `sections.whatWeDo` |
| Files | `what-we-do.njk`, `.css` |

## How it works
The most-asked question before anything else is "do you design, build, or both?". Each service is one row: its name
and one sentence in the studio's words. With `design-build-care` on, the name links to that service's page.

# The journal

| | |
|---|---|
| Feature id | `garden-journal` (page `journal.html`, and one page per article) |
| Plan | plus and above |
| Config | `journal`: `kicker`, `title`, `intro`, optional `note`, `items`: `slug`, `title`, `date` (YYYY-MM-DD), `summary` (up to 160 characters), `photo`, `body` (paragraphs separated by a blank line), optional `sources` (`{ label, url }`) |
| Files | `garden-journal.njk`, `.css`; an article is `partials/article.njk` |

## How it works
The studio's own writing (what to plant each season, designing a small garden, caring for a new lawn), newest first,
each article dated, on its own page, with its sources where it states a general fact.

# Kinds of garden

| | |
|---|---|
| Feature id | `style-pages` (one page per kind; a collection, counted as one page) |
| Plan | signature; needs `gardens` |
| Config | `stylePages.items`: `style` (a `gardens.styles` id), `slug`, `title`, optional `kicker`, `intro`, `description` (up to 160 characters), `body` (paragraphs separated by a blank line), `photo` |
| Files | `style-pages.njk`, `.css` |

## How it works
A page each for the kinds of garden the studio is asked for (roof terraces, courtyards, country estates): what's
particular about them in the studio's words, then every garden of that kind, each to its story when it has one. The
garden cards are shared with the gardens feature.

# How we help (Starter)

Up to four services as columns: a 4:5 photograph, a fine accent line, a title and one sentence. Each opens its
moment's page (`event`, Signature) or its anchor on the approach page (Plus). `audience` and `minimum` are the firm's
own words about who it works with (WEALTH 1); a demo's minimum is marked as demo copy.

```json
"services": { "audience", "minimum", "items": [{ "id", "title", "line", "photo": { … }, "event", "navLabel" }] }
```

`navLabel` puts the service in the header under a shorter name ("Business owners").

# The family map (Signature showpiece)

Before a first meeting, a family sketches who is who across four generations and the advisers they already have
(solicitor, accountant, trustees). It is kept in the visitor's browser only (localStorage); nothing is sent. They can
copy it as text into an email to themselves, print it, or start again. No figures and no money questions.

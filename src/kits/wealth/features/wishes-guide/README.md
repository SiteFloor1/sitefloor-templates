# Letter of wishes, a guide (Signature)

General information about a letter of wishes in England and Wales: what it is, that it isn't binding, what people put
in it, that it stays private when a will becomes public after probate, and how to write and keep it. Every part names
its source (The Gazette / Lodders Solicitors, Forsters LLP, GOV.UK) and the page shows the date it was checked. The
facts live in `../../lib/wishes.js`; a firm can change only the page's title and opening line:

```json
"wishesGuide": { "title": "A letter of wishes", "intro": "…" }
```

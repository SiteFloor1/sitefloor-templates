# Arrange a meeting (Plus)

A short request written into the visitor's own email (or WhatsApp): name, how to reply, what it's about (the
situations), where (the firm's choices), someone in particular, when suits (WEALTH 5). It asks nothing about money,
and it refuses to send anything that looks like an account, card or sort-code number. Nothing is stored. Without
scripts it shows the phone number and email instead. The "What to bring" list sits beside it when `bring` is on.

```json
"meeting": { "title", "intro", "email": "meetings@firm.example", "where": ["At our office", "At your home", "By video"], "note" }
```

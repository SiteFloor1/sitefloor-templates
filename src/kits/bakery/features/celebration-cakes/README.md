# Feature: celebration-cakes (bakery kit, Plus, page `/cakes`)

The celebration cakes page: the shop's own cake photos, sizes with servings and "from" prices, sponges, fillings,
finishes and toppings with their extra prices and allergens, the earliest day one can be made (notice, cut-off, closed
days, and days marked full in the `bakes` sheet), a request form (size, flavours, finish, colour, the name on the cake,
collection day) that prices the cake and sends it on WhatsApp, the deposit (`pay-link`) and "Remind me to order again
next year" (an all-day calendar reminder a year on, early enough for the notice). Uses the same `cakes` settings as the
Cake Builder; see `../cake-builder/README.md`. Page copy: `cakesPage`.

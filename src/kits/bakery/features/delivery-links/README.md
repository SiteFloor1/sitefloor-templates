# Feature: delivery-links (bakery kit, Starter)

Links to the shop's own pages on the delivery apps, and a collection line (with a link to `collect` when it's on).

```json
"delivery": { "apps": [{ "name": "Deliveroo", "url": "https://deliveroo.co.uk/menu/…" }], "collection": "…", "lateUntil": "00:30" }
```

`name`: Deliveroo, Uber Eats, Just Eat or Our own delivery. Heading: `sections.delivery`.

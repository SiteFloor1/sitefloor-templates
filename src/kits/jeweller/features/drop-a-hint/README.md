# drop-a-hint (jeweller kit, Starter)

"Drop a hint" beside every piece (in the piece viewer and on piece pages): sends the piece's name, its price as the
client sets it (or nothing) and its link to someone the customer chooses, through the phone's own share sheet, or
WhatsApp with the message written and no number when there's no share sheet. Nothing goes to the house.

Hidden until its script runs (a button that does nothing without JavaScript is never shown). No config: it uses
`pieces`. Text: `hintText` in `src/kits/jeweller/lib/messages.js`.

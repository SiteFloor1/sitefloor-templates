# anniversary-reminder (jeweller kit, Plus)

Anniversary reminder: the customer gives the date (and whose it is, in their words) and how much notice they want
(the house's choices, e.g. 2, 4 or 6 weeks); a calendar file (.ics, every time in UTC, at 10am shop time) reminds them
every year, with the house's name and link. Made in the browser; nothing is sent to the house. On the Gifts page (or
the home page without it). Config `anniversary`: `weeks`, `line`. Section copy: `sections.anniversary`.

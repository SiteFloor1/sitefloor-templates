# birthstone (jeweller kit, Plus)

Birthstones: on the home page, this month's stone (the month in giant capitals, the stone, the house's line, its piece
for the month); on the Birthstones page (`/birthstones`), every month with the house's pieces for it, this month
marked. Every month is in the page and the script shows today's (in the shop's timezone), so it moves on by itself.

The list of stones is the client's own (`birthstones.months`, twelve, January first: `stone`, optional `line`); pieces
name their months with `months` (1–12). Page copy: `birthstones.title`, `intro`.

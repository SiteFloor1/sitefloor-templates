# in-the-box (jeweller kit, Starter)

The brand moment on the home page: one full-width band of the house's signature colour (the look's `--brand`, which
follows the client's own accent), with the client's own box photographed in it, the monogram large and the house's
one line. On a client site the photograph is their own box (ideally with their mark on it). What comes with every
piece (`box.items`) shows on piece pages and the Gifts page, only in the client's words: never a guarantee,
certificate or valuation they don't give (refused here). Config `box`: `photo`, `line`, optional `items`. Section
copy: `sections.box`.

# piece-viewer (jeweller kit, Starter)

One piece at a time. Tapping any piece card (on the home page, the pieces page, bridal, gifts…) opens it full screen
with its name, spec line, price and facts, exactly as the client gives them; Previous/Next, the arrow keys or a
sideways swipe step to the next piece. Photos load only when shown. Its actions: see it in person (WhatsApp, naming
the piece), set it aside on the tray (Plus), drop a hint, its page (Plus).

The viewer is a `<dialog>` included once per page by the look's footer. Without JavaScript, cards are plain links
(the piece's page, or the appointment section). Demo sites add a note that specs and prices are the demo's.

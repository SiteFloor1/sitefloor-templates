# pair-it (jeweller kit, Signature)

Pair it: an engagement ring beside each wedding band the house suggests for it, both from the house's own photographs,
side by side at the same height. Choose a band and "Ask to see the pair" names both on WhatsApp. Without JavaScript
every suggested band is shown beside the ring. Photographs are never combined into one picture.

Config per ring: `pairs` = the ids of the bands (pieces). Shown on the ring's page and on the Wedding bands and Bridal
pages. Needs `jewel-pages`.

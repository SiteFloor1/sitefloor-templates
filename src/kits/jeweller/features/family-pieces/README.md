# family-pieces (jeweller kit, Plus)

The Family pieces page (`/family-pieces`): remodelling something inherited. Each before and after from the house's
own photographs, one over the other with a slider (side by side without JavaScript), and the house's line about it;
what can be kept (the stones, the gold, an engraving…); how it starts, with "Send a photograph of the piece" on
WhatsApp. Config `family`: `title`, `intro`, `pairs` ([{ `before`, `after`, `text` }]), `keep`, `start`, optional
`description`; a demo may add `demoNote`.

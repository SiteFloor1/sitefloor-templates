# wedding-bands (jeweller kit, Plus)

The Wedding bands page (`/wedding-bands`): every band in the house's bands collection as a long horizontal entry
(photograph, name, spec, price as the client sets it, actions), the house's own notes on widths and finishes, then
engraving inside the band and Pair it (both Signature). Config `weddingBands`: `title`, `intro`, `collection` (the
bands' collection id), `notes` ([{ `title`, `text` }]), optional `description`.

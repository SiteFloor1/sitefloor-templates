# engagement-guide (jeweller kit, Plus)

The Engagement guide page (`/engagement`): shapes in the house's own photographs (with `stone-guide`), metals and
settings in two columns of the house's own words, how sizing works (with the ring sizer's page), and planning a
proposal (Signature, `proposal-brief`). Every word is the client's: the page never states hardness, purity or
durability figures on its own. Config `engagementGuide`: `title`, `intro`, `metals`, `settings` ([{ `title`, `text` }]),
`sizing`, optional `description`.

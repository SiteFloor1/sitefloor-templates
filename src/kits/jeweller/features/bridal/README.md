# bridal (jeweller kit, Plus)

The Bridal page (`/bridal`): the house's photograph and its words on how a ring is chosen (`words`), then each bridal
collection as one long row of pieces (they open in the piece viewer), "Pair it" for the first ring with suggested
bands (Signature), the ways on to the engagement guide, wedding bands and ring size, and the appointment.
Config `bridal`: `title`, `intro`, `collections` (ids), optional `words` ([{ `title`, `text` }]), `photo`, `description`.

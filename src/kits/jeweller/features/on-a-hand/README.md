# on-a-hand (jeweller kit, Signature)

See it on a hand: on a piece's page, the house's photograph of the piece worn. When the client has measured the real
width the photo shows (`hand.widthMm`, taken with a ruler beside the hand), "Show it at true size" draws it at that
size on this screen: the visitor matches an outline to a bank card held against the glass once (an ID-1 card is
85.60 mm wide), and the scale is kept on the device (also used by the ring sizer). Without a measured width it is
simply the photograph. Hidden parts need JavaScript; the photo always shows.

Config per piece: `hand` = { `photo`, optional `widthMm` (30–250), optional `size` (UK letter worn in the photo) }.
Needs `jewel-pages`. Demo photos are stock, so their width is estimated and labelled as such.

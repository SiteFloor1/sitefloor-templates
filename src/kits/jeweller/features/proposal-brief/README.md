# proposal-brief (jeweller kit, Signature)

Planning a proposal: the day they'll ask, the partner's ring size if known, what they usually wear and a budget
band (the house's own choices), sent privately on WhatsApp so the house can help choose and prepare. A request,
nothing more. On the Engagement guide page (or the home page without it). Config `proposal`: `line`, `styles`,
`budgets`. Section copy: `sections.proposal`.

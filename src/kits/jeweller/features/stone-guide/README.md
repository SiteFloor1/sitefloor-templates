# stone-guide (jeweller kit, Plus)

The stone guide: every shape the house sets (round brilliant, oval, emerald cut, pear…), each in the house's own
photograph with its own words and the house's pieces in that shape (they open in the piece viewer). Tabs on screen;
without JavaScript, one after another. Config `stones` = [{ `id`, `name`, `photo`, `text` }]; pieces name their
shape with `shape`. A shape with no piece is refused. Section copy: `sections.stones`. On the Engagement guide page
(or the home page without it).

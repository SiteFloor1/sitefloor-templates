# letting-repairs: report a repair (Plus)

A page for tenants: what counts as an emergency and the out-of-hours number (with the National Gas Emergency line,
0800 111 999, always first), then a short form that writes the WhatsApp message (the home, what's wrong, where,
whether the agent may use its keys). The tenant adds photos in WhatsApp. The site sends and keeps nothing.

Settings (`repairs` in site.json): `title`, `intro`, `emergencyIntro`, `emergencies` (lines, in the agent's words),
`outOfHours` (a phone number), `message` (the start of the WhatsApp message).

# letting-residences: the residences schedule (Signature)

A page: every building in `homes.buildings` as a column, floors as rows (top floor first), each free home with its
rent, name, bedrooms and size, from the same sheet as the home page; a let floor says "Let", a floor's `note` stands
instead, a building without that floor shows a hatched cell. A home opens its card (letting-board's). On a phone,
one building at a time. Fails closed like the board: a stale sheet lists nothing and says to call. Needs `letting-board`.

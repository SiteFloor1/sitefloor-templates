# letting-valuation: what would my home let for? (Signature)

The owner's showpiece. A page with one sentence to complete ("My [2]-bedroom [flat] of about [85] [m²] with [2]
bathrooms, at [address] [postcode]"), a few optional details and the agent's services; "Ask … for a figure" opens
WhatsApp with all of it written out. **No automated figure, ever**: the agent replies. Settings (`valuation`):
`title`, `intro`, `kinds` (the kinds of home, e.g. Flat, House, Maisonette), `message` (opening line), `reply` (how
and when the agent answers), `next` (lines).

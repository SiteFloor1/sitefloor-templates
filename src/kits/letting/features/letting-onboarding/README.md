# letting-onboarding: onboarding for owners (Signature)

A page: the steps from the first call to the first rent (`steps`: `title`, `text`, `you` (what the owner brings),
`time`), then the papers a let needs as a checklist the owner ticks on the page; it sends one WhatsApp message with
what's ready and what's still to sort. Nothing is stored. Settings (`onboarding`): `title`, `intro`, `steps`,
`checklistIntro`, `checklist` (lines), `message`. The agent words the steps and checklist; the kit invents none.

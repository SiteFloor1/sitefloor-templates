# letting-manage: what we manage (Plus)

A page: how many homes the agent looks after (counted from `homes.buildings`, never typed in), the kinds of home it
takes on, a managed let's year month by month, and what it doesn't take on. Settings (`manage`): `title`, `intro`,
`kinds` (`name`, `text`), `year` (`when`, `what`), optional `not` (lines). All in the agent's own words.

# letting-net: one rent, from both sides (Signature)

A home-page section. One monthly rent the visitor can retype (`fees.example`, default £2,000): on one side what a
tenant pays before the keys (holding deposit, deposit of five or six weeks, first month: lib/fees.js, the GOV.UK
caps), on the other what reaches the owner under each service in `fees.services` (the agent's own rates, with VAT).
Worked out at build time for the example rent, so it reads the same without JavaScript. Ends with the redress and
client money protection line and a link to the fees page. Labelled an illustration, not advice.

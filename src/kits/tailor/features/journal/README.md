# journal (tailor kit, Plus, page `journal` and a page per article)

The house's own writing (choosing cloth by season, what to wear to a wedding, caring for a suit), dated and signed,
newest first; each article on its own page with its photograph and any sources. The articles are one collection and
count as one page. Every article is the client's writing: never filler, never invented facts.

# the-process (tailor kit, Starter)

How a commission runs, one line a step, from `process.steps` (the same steps the process page and the commission
tracker use). Links to the process page when that page is on.

```json
"process": { "steps": [{ "id": "cut", "name": "Cut", "text": "Your pattern drafted, then the cloth cut.", "more": "…", "photo": { "src", "width", "height", "alt" } }] }
```
Heading: `sections.process`. `more` and `photo` are for the process page and the tracker.

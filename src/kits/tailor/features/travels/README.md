# travels (tailor kit, Plus, page `trunk-shows`)

Trunk shows by city, soonest first: city, dates (UK order), venue and a line; "Ask for a slot" sends a pre-filled
WhatsApp message with the city, venue and dates; "Add to calendar" downloads all-day events. Finished trips drop off
at the build and in the browser. With none announced, one line and a WhatsApp link.

```json
"travelsPage": { "kicker": "Trunk shows", "title": "Where we'll be", "intro": "…" },
"travels": { "message": "Hello Fennick & Lowe.", "items": [{ "id": "edinburgh-nov", "city": "Edinburgh", "venue": "…", "from": "2026-11-19", "to": "2026-11-21", "text": "…" }] }
```

# reorder (tailor kit, Signature, page `from-your-pattern`)

Your pattern on file. A returning client re-orders from the paper pattern the house keeps: the code on their order card,
the garment (from `garments`), the cloth (from the cloth book, "the same as last time" or "help me choose") and any
change in their own words, sent as one WhatsApp message from their own phone. The site stores nothing and never asks
for a measurement; the house matches the code to the pattern it holds. The Send link waits until the code looks like
one (8–12 letters and numbers, as the commission tracker uses). Without JavaScript the slip is a plain WhatsApp link.

```json
"reorder": { "kicker", "title": "From your pattern", "intro", "message": "Hello Fennick & Lowe.",
  "note": "We keep your pattern at the house; this site keeps nothing.", "photo": { "src", "width", "height", "alt" } }
```

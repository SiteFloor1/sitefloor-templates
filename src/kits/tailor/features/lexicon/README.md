# lexicon (tailor kit, Signature, page `lexicon`)

The style lexicon: the words a cutter uses, one plain sentence each, with a photograph where the house has one
(4:5), filtered by kind (lapel, pocket, button, back, shoulder, trouser, cloth; only the kinds used are offered). Each
word has its own anchor (`lexicon.html#peak`) so the cloth and process pages can link to it.

```json
"lexicon": { "kicker", "title", "intro", "items": [{ "id": "peak", "term": "Peak lapel", "kind": "lapel", "text": "…", "photo": { "src", "width", "height", "alt" } }] }
```

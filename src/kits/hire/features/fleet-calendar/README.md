# Feature: fleet-calendar (hire kit)

The fleet calendar on the fleet page. **Plan:** Plus. A fortnight at a time (up to eight weeks ahead), a row per
self-drive car grouped by class and a column per day: free on the calendar (links to the car's dates), taken, or closed
for handovers (the business's own hours). Today is the business's UK date, never the visitor's. The days come from the
same availability Sheet as everything else and fail closed: no Sheet, an error or old data shows no day as free and
says "ask us". Without JavaScript, a line to ask. Firms can use it as their own at-a-glance board.

# garage-night (Plus; with the aerial hall, Signature + Bespoke)

Arrive at night (PARK-11), its own page (`/arrive-at-night`), and its first three steps on the home page.
`night`: `{ intro?, steps: [{ title, text?, photo? }] }`, the client's own words and photographs, gate to bay. With
garage-aerial on, the night render (`aerial.night`, `aerial.nightPhone`) heads both, and the route from the gate to
the bay the visitor's car fits is drawn over it (it follows the car picked in the hero).
The line for the visitor's bay is the kit's, not a step: "Bay 7 is lit and waiting, its charger on.", naming the
charger only when the bay has one (or the waiting list, by the car's name). It sits after the client's second step,
and follows the car picked on the home page; the home page's link carries it to the night page (`?car=suv`), which
says which car the route is for. So the client's own steps never name a bay. The night render is a true
night pass of the same scene, not the day render dimmed.

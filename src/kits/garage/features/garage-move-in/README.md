# garage-move-in (Starter)

Moving in to your calendar (PARK-12). `moveIn.steps`: `{ day, title, note? }`, `day` counted from the first day
(0 = the first day, -2 = two days before, 27 = the last day to give notice on a 28-day month). The visitor picks
their first day; the steps are dated and offered as a calendar file (.ics) made in the browser. Nothing is stored.

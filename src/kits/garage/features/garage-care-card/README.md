# garage-care-card (Signature)

Your car this month (PARK-18). `careCard`: `{ checks, every, sample }`: the checks the client makes ("Battery",
"Tyre pressures", "Cover back on", "Started and moved"), how often ("month"), and one card as the client writes it.
The page shows that card (labelled sample on a demo, example on a client) and a link asking for the visitor's own
by WhatsApp; a car's card is never published.

# garage-charging (Plus)

Charging (PARK-15). A bay's speed is `charger` (kW) on the bay in `hall.rows`; `charging`: `{ plugInBy, readyBy,
note? }` ("22:00", "07:00") give "Plug in by 10pm, charged by 7am." Shown as a list here; with the drawn plan
(garage-pick) or the aerial hall (garage-aerial), the charger bays glow on them too.

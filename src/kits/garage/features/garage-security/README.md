# garage-security (Plus)

Security (PARK-16). `security`: `{ recorded, facts, cameras? }`. `recorded` says how footage is kept ("Recorded and
kept for 30 days; never a live feed"); the site never offers a live feed and the check refuses one. `facts` are the
client's own lines (gate, fob hours, alarm). `cameras`: `[{ x, y, facing }]` in hall metres (facing in degrees, 0 =
towards the east wall, 90 = north); with the drawn plan or the aerial hall their coverage shows on the floor.

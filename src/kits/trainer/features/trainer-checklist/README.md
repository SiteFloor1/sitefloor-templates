# trainer-checklist (Plus, PT-8)

What to wear, eat and bring, and the night before, as a list to tick on the phone (nothing stored, nothing sent), with
the cancellation policy in the trainer's words. Lives on the Start here page when `trainer-start` is on.

```json
"checklist": {
  "title": "Before your session", "intro": "…",
  "groups": [{ "label": "The night before", "items": ["…"] }],
  "cancellation": "Twenty-four hours' notice and there's no charge…"
}
```

# trainer-journal (Signature, page `journal` + a page per article)

The trainer's own short articles. Each is a page (`article-<slug>`). No dates are shown, so nothing goes stale.

```json
"journal": { "title": "Journal", "intro": "…",
  "articles": [{ "slug": "starting-strength", "title": "…", "intro": "…", "minutes": 4, "photo": { … }, "body": ["…"] }] }
```

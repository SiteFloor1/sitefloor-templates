# trainer-coverage (Plus, PT-5)

"Do you come to me?": a postcode against the trainer's own districts, for each way they travel (to your home, to a
park). Every list is printed, so it works without JavaScript. Lives on the At home and online page when
`trainer-online` is on (home.js HOSTS), otherwise on the home page.

```json
"coverage": {
  "title": "Do you come to me?", "intro": "…",
  "areas": [{ "id": "home", "label": "At your home", "districts": ["SW1X", "SW3"], "note": "…" }],
  "elsewhere": "Further out, we can train online."
}
```

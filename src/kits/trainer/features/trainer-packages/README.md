# trainer-packages (Signature, PT-7, page `corporate`)

Team sessions for a company and family sessions at home: who each is for, what's included, the price from (the
trainer's own) and how many people at most; a request (which, how many, days that suit, a company or family name)
written into a WhatsApp message.

```json
"packages": {
  "title": "Companies and families", "intro": "…", "photo": { … }, "invoice": "Companies are invoiced monthly…",
  "message": "Hello, I'd like to ask about a package:",
  "items": [{ "id": "office", "kind": "corporate", "name": "At your office", "who": "…", "people": 8,
              "includes": ["…"], "priceFrom": 180, "unit": "a session for the group" }]
}
```

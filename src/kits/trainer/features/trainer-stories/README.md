# trainer-stories (Plus, PT-4, page `results`)

Clients in their own words. No photographs (before/after pairs are never shown), no numbers; the kit's copy check
refuses promised results in every story. The Results page also holds the shared `reviews` when on.

```json
"stories": {
  "source": "client", "title": "In their words", "intro": "…",
  "items": [{ "name": "Hannah", "programme": "strength", "since": "2025",
              "words": ["Their own words."], "consent": { "date": "2026-10", "how": "in writing, by email" } }]
}
```

`source: "client"` needs `consent` on every story (when and how the client agreed to be quoted). `source: "sample"` is
refused on client sites; a demo's samples carry a visible note.

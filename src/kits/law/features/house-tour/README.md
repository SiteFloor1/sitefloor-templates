# The house, room by room (Signature, page `house`)

One large photograph with the rooms listed beside it; choosing a room cross-fades its photograph. Without scripts every room is stacked.

## Config

```json
"house": { "title", "intro", "rooms": [{ "id", "name", "line", "photo": { "src", "width", "height", "alt", "position" } }] }
```

Markup is neutral and styled with tokens; each look restyles it.

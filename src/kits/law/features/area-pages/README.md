# Practice area pages (Signature)

One page per area (`area.njk`, permalink = area id): the work, who leads it, people, guides and insights on it, approved matters, prices. A collection, counted as one page.

## Config

Uses `practice`, `people`, and `guides`, `insights`, `matters` when on.

Markup is neutral and styled with tokens; each look restyles it (and may override it in `src/looks/<look>/features/`).

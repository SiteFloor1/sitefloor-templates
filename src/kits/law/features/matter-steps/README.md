# Your matter, step by step (Plus)

The firm's own stages for a kind of matter as a timeline, on the practice page and each area page.

## Config

```json
"matterSteps": { "title", "matters": [{ "id", "practice": "<area id>", "name", "steps": [{ "title", "when", "text", "you" }] }] }
```

Markup is neutral and styled with tokens; each look restyles it.

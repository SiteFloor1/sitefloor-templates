# Will review reminder (Plus)

Tick what has changed since the will was made: any tick suggests a review with the practice lead's email; none offers a calendar reminder in `years`. On the practice page (under the named area), that area's page and the guides page.

## Config

```json
"willReminder": { "title", "intro", "practice": "<area id>", "years": 3, "events": [{ "id", "label" }] }
```

Markup is neutral and styled with tokens; each look restyles it.

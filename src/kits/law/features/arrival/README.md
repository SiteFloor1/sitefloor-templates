# Discreet arrival (Plus, home)

Which door, where to leave the car and who opens it, beside a photograph of the house. The meeting pack reuses the ways in.

## Config

```json
"arrival": { "title", "text", "ways": [{ "id", "label", "text" }], "photo": { "src", "width", "height", "alt", "position" } }
```

Markup is neutral and styled with tokens; each look restyles it (and may override it in `src/looks/<look>/features/`).

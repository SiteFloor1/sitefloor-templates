# card-composer (florist kit, Plus)

The card, inside this week's band: "Add a card" opens a box; the florist's card shows the words as they're typed,
held to the florist's own length and number of lines. The words go into the WhatsApp order with the flowers. Optional
starting lines help when words are hard.

```json
"card": { "max": 200, "lines": 6, "from": "<your shop> · <area>", "starters": ["Happy birthday.", "Thinking of you."] }
```

# rooms-we-dress (florist kit, Plus)

Rooms we dress: homes, hotels, restaurants and events, one large photograph at a time with one line each. Tabs on a
computer (arrow keys move between them), a sideways strip on a phone, every room listed without JavaScript.

```json
"rooms": { "items": [{ "id": "gallery", "title": "The long gallery", "line": "One urn, changed every Monday.", "photo": { … } }] }
```

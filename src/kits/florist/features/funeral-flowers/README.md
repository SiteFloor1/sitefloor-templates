# funeral-flowers (florist kit, Plus, page `funeral`)

Funeral flowers, separate from the sympathy order: the pieces (wreaths, sprays, tributes) in the florist's photographs
with their starting prices, the notice they need and how delivery to the funeral director works (in their words, as
questions and answers), a short note and one WhatsApp button. Plain words; no countdowns, offers or the week's colour.
Links to the sympathy page when that's on.

```json
"funeral": { "title": "Funeral flowers", "intro": "…", "photo": { … }, "message": "Hello <your shop>, I'd like to ask about funeral flowers.",
  "pieces": [{ "id": "wreath", "title": "A wreath", "line": "…", "from": 120, "photo": { … } }],
  "notice": [{ "q": "How much notice do you need?", "a": "…" }], "note": "…" }
```

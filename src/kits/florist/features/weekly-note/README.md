# weekly-note (florist kit, Starter)

A short note from the florist under this week's stems: what came in, what to look out for. Signed with the studio's
name or the florist's. With the studio Sheet on, rows `note,text,…` and `note,from,…` change it (240 and 40
characters at most, otherwise the built note stays).

```json
"note": { "text": "The first English roses of autumn came in on Tuesday…", "from": "Nell, at the bench" }
```

# remember-date (florist kit, Signature)

Remember the date: whose day, what it is and the date go into the customer's own calendar as a yearly event at 9am
shop time, with a reminder `orderDaysBefore` days before to order. Made in the browser as an .ics file; nothing is
sent to the florist or stored.

```json
"remember": { "orderDaysBefore": 1, "kinds": ["Birthday", "Anniversary", "Mother's Day"] }
```

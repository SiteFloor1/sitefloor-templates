# care-card (florist kit, Plus, page `flower-care`, unlisted)

The care card: a short page of the florist's own care advice, reached from a QR code printed on the card that goes
with every bouquet. The QR code is drawn on the page (made at build time, an SVG of the site's own address; no
service, no tracking) so the florist can print it. Free (doesn't count towards the plan's pages) and kept out of
search and the sitemap.

```json
"care": { "title": "Your flowers", "intro": "…", "steps": ["Trim each stem…", "…", "…"], "lasts": "Most bouquets last a week…" }
```

# gifts-to-add (florist kit, Plus)

Something to go with this week's flowers: the florist's own vases, candles and cards, with their prices and photos,
in a fold under the sizes. Ticked items go on the WhatsApp order as `Add: Ribbed vase (£28)`. Up to six.

```json
"gifts": { "title": "Add a vase, candle or card", "items": [
  { "id": "vase", "name": "Stone vase", "price": 28, "photo": { "src": "img/gift-vase.webp", "width": 500, "height": 500, "alt": "…" } } ] }
```

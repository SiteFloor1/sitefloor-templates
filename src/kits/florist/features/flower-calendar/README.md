# flower-calendar (florist kit, Signature, page `calendar`)

The flower calendar: twelve months, January first, each with the florist's photograph, the stems at their best and a
line in their words. This month is marked in the browser by the shop's clock. With the wedding planner on, each month
links to the wedding enquiry (`weddings?month=5`, which sets the month in the date field when empty) and the closing
line links to a palette from a swatch.

```json
"calendar": { "title": "The flower calendar", "intro": "…", "weddingLine": "…",
  "months": [{ "stems": "Amaryllis, hellebores, forced narcissi", "line": "…", "photo": { … } }, … twelve ] }
```

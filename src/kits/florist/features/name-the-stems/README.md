# name-the-stems (florist kit, Signature)

Name the stems: small rings over this week's photograph (the look's hero); tap one to see what it is ("Coral garden
rose · English-grown"); "Name the stems" opens every name at once. The florist marks each stem once a week as a
position in % on the photo (`x`, `y`) and, if the phone crop is different, on the phone photo (`px`, `py`). The rings
are placed on the photograph as it's cropped on the screen, so they stay on the flower at any width. They show only
on the photo they were marked on (`photo`): a different photo from the Sheet hides them unless the Sheet marks stems
too, one row each: `stem,1,62 40 55 48 | Coral garden rose | English-grown`. Needs JavaScript; nothing shows without it.

```json
"stemNames": { "photo": "mantel", "points": [{ "x": 44.5, "y": 48, "px": 40.5, "py": 46, "name": "Coral garden rose", "note": "English-grown" }] }
```

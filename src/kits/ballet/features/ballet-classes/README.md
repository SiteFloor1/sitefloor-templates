# Classes by age

| | |
|---|---|
| Feature id | `ballet-classes` (needs `ballet-finder`) |
| Plan | plus and above |
| Config | `classes` (see `ballet-finder`); `classesPage` `{ kicker, title, intro }` |
| Files | `ballet-classes.njk` (the classes page), `ballet-classes.css` |

## What it does
Every class from the youngest up, grouped by the same age ranges as the finder: the age large in the margin, then each
class's name, days and times, length and the school's own line. With `ballet-path` on, "Where she'll go next" follows.

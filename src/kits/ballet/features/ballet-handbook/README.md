| | |
|---|---|
| Feature id | `ballet-handbook` |
| Plan | signature |
| Config | `handbook`: `updated` (YYYY-MM, when the school last checked it), `sections` `[{ id, title, body }]` (blank line between paragraphs); `handbookPage` `{ kicker, title, intro }` |
| Files | `ballet-handbook.njk` (the handbook page), `ballet-handbook.css`, `ballet-handbook.js` |

## What it does
Everything a parent needs for the year in one place: collection, photographs and filming, what to bring, illness,
behaviour in the studio. A contents list stays in the margin; "Print the handbook" prints it cleanly.

## Rules
- All wording is the school's own. Safeguarding, DBS checks and first aid appear only as the school's own statements.

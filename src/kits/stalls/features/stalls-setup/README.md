# The set-up card

| | |
|---|---|
| Feature id | `stalls-setup` |
| Plan | signature |
| Config | `setup`: `rows` [{ `label`, `value` }], `intro?`; `sections.setup` |

What the stall needs on the day (pitch size, power, cover, water, arrival and pack-down times, paperwork), in its own
figures, as a card an organiser or venue can use. "Copy for the organiser" puts it on the clipboard as plain text;
"Send on WhatsApp" opens it as a message. A line the stall doesn't give isn't shown. On the Parties and private hire
page and the Book us page.

Registered in `src/kits/stalls/kit.js`.

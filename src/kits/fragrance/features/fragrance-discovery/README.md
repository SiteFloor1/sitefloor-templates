# Discovery sets (FRAG-3, Plus)

`discovery`: `title`, `intro?`, `pick` (how many samples a set holds), `ml` (each sample), `price` (the set),
`terms` (the house's discovery terms, e.g. what's taken off a full bottle), `message` (the WhatsApp order:
`{fragrance}` is the chosen names, `{price}`) and, on a client site, `payLink` (the house's Stripe link for the set;
the choice then follows on WhatsApp). The set fills as the visitor chooses; no stock or "selling fast".

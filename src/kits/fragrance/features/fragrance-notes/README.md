# Notes on the bottle (FRAG-5, Signature)

The hero fragrance's notes (`fragrances.items[].notes`, the house's own) as one sentence in three clauses, set at the
bottle's own heights on the hero picture: top at the neck, heart at the shoulder, base at the foot (`hero.marks`,
measured once as fractions of the picture: `neck`, `shoulder`, `base`, `xl`, `xr`, `floor`). Tap a note to read which
other scents in the house list it. Only the house's notes; a missing tier drops its clause and the sentence still reads.

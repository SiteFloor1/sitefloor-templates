# The organ (FRAG-2, Plus)

`organ`: `title`, `intro?`, `max?` (how many to choose, 3 by default), `note?`, and `ingredients`: each `note` (a note
the house lists in `fragrances.items[].notes`; one no fragrance has is refused) with a `photo` of the real ingredient
and `credit?`. The photos show in black and white; chosen ones turn to colour and the fragrances that list them rise,
most matches first, each saying which it has. Only the house's notes; never "you'll love it". Its page: Scent finder.

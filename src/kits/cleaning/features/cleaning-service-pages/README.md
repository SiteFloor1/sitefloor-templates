# A page for each service (cleaning kit, Signature collection)

Each service with `page` gets `<id>.html`: its sections in the company's words, an optional photograph (the company's
own, or credited licensed stock on a demo), its rate and how long it usually takes, and "Ask about …" on WhatsApp.
Counted as one page. Settings: `cleans.items[].page` ({ intro, sections, photo?, takes? }).

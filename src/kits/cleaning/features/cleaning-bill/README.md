# The bill (cleaning kit, Plus)

Under the strip: the extras with their minutes, then every room and extra in minutes, time on site, the shortest visit
if it applies, the hourly rate and one price, rounded once; "Send this on WhatsApp" carries the same words and figures.
It follows the strip (`cleaningVisit`) and sends its extras back (`cleaningExtras`); both read `visit()`, so the strip,
the bill and the message can't disagree. Settings: `visit` (see cleaning-strip) and `sections.bill` ({ title, intro, fine }).

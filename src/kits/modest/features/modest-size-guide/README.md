# modest-size-guide (Starter)

The size guide by height (MOD-2): the shop's own chart (`lengths.chart`: height, shoulder-to-floor band, length to wear
in flat shoes) and how to measure (`lengths.measure`). Heading: `sections.sizeGuide`. No JavaScript.

With `modest-hem-line` on, the chart moves inside the hem line behind "Only know your height?", and this section is
not repeated on the home page. Chart settings: see `modest-hem-line`.

# modest-category-pages (Plus)

A page for each part of the collection (`pieces.categories`, each with `page: { title, intro? }`), at `/<id>`: every
piece in that part as on the home page, photograph or not. Each part counts as a page of the plan (checked in
`config.js`). With it on, the Taroub header writes the parts as its first sentence ("Abayas, occasion wear and hijabs.").

# registers (electrician kit, Starter, ELEC-3)

The client's accreditations (NICEIC, NAPIT, Stroma, the Electrical Competent Person register, TrustMark, Which?
Trusted Traders, OZEV), each linked to its own entry on the scheme's public register. Only from the client: never
add a scheme they haven't shown you a certificate for. The validator only accepts a link on the scheme's own site.

```json
"registers": [{ "scheme": "niceic", "label": "NICEIC Approved Contractor", "url": "https://www.niceic.com/find-a-contractor/…" }]
```
Shown beside the services (`circuits` must be on).

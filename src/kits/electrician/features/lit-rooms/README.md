# lit-rooms (electrician kit, Starter)

Rooms, lit: 2–6 of the client's own photographs of finished rooms at night (kitchen, living room, cinema, bathroom…),
each with the room's name, the scene it's in and one line on what was done. A row on large screens; on phones it
scrolls sideways and stops on each room.

```json
"rooms": { "items": [{ "id": "kitchen", "name": "Kitchen", "scene": "Evening", "did": "Pendants on their own dimmer, light under the cabinets.", "photo": { "src": "img/room-kitchen.webp", "width": 960, "height": 1200, "alt": "…" } }] }
```
Heading: `sections.litRooms`. Photographs of the client's own jobs only (a demo says its photos are stock).

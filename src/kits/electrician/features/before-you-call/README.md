# before-you-call (electrician kit, Plus)

Before you call: how old the house is, which rooms, what's wanted (the client's own choices) and a note, sent as one
tidy WhatsApp message, with a reminder to attach a photo of the fuse board. The first visit can then bring a quote.
Nothing is stored; the message is the visitor's to send.

```json
"beforeYouCall": { "message": "Hello <your business>, before we speak:", "ages": ["Before 1919", "1919–1960", "1960–2000", "Since 2000"], "goals": ["Lighting design", "A rewire", "Smart home", "A car charger"] }
```
Heading: `sections.beforeCall`.

# dimmer (electrician kit, Plus)

The dimmer: 2–5 of the client's own photographs of one finished room, taken from one spot (a tripod) with the lights
at different levels, darkest first. A fader cross-fades between them, so between two frames both are partly seen, as
a real dimmer looks. Real photographs only: the page never simulates light. Without JavaScript the brightest
photograph shows.

```json
"dimmer": { "label": "Dim the garden room", "note": "…",
  "frames": [{ "src": "img/dim-low.webp", "width": 1500, "height": 1000, "alt": "…", "label": "Low" }, { "src": "img/dim-full.webp", "width": 1500, "height": 1000, "alt": "…", "label": "Full" }] }
```
Every frame must be the same size. Heading: `sections.dimmer`.

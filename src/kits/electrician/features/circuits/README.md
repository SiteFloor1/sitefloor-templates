# circuits (electrician kit, Starter, ELEC-1)

Services, and what each includes, set as the chart inside a fuse board's door: one numbered circuit per service.
Each row opens (a native `<details>`, so it works without JavaScript) to the client's own lines about what's included.

```json
"circuits": { "items": [
  { "id": "lighting", "name": "Lighting design and control", "included": ["A lighting plan for every room", "Scenes on one keypad"] }
] }
```
Heading: `sections.circuits` (`title`, `intro`). 1–12 services. The registers (`registers`) sit beside the chart when on.

# call-out (electrician kit, Starter, ELEC-2)

The emergency line at the top of every page: a sentence, when they come out, and the phone number as a `tel:` link.

```json
"callOut": { "line": "Lost power, or a burning smell?", "when": "Emergency call-outs, day and night.", "message": "Hello, I have an electrical emergency." }
```
Only say "day and night" if the client really answers then. `message` opens the WhatsApp message the fault guide sends.

# project-page (electrician kit, Plus)

A page, `/your-project`, for everything about starting a job: how a project runs (`project-steps`), Before you call
(`before-you-call`) and, on Signature, the whole-house estimate (`estimate`). The look moves those sections here from
the home page when this page is on (look.json `onPages`), which keeps the home page short.

```json
"yourProjectPage": { "kicker": "Your project", "title": "From the first visit to your certificates", "intro": "…" }
```

# Collaborations (`popup-partners`, Signature, page `collaborations`, client-only)

The brand's real partners and what they made together, each with a link. Only ever the brand's own; a demo never
carries invented collaborations, so this feature is client-only (`npm run rules`). Uses the press list's styles.

```json
"partners": { "title": "Collaborations", "items": [{ "name": "…", "line": "…", "url": "https://…" }] }
```

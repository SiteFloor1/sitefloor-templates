# The opening countdown and waitlist (`popup-waitlist`, Plus, page `waitlist`)

The days until the next stop opens ("44 days until Manchester"), worked out from the stops in `popup` for the
visitor's day, Add the opening to calendar, and a way onto the brand's own list: its Google Form (`formUrl`), or a
pre-filled WhatsApp message when there is no form. The site collects nothing itself and never shows how many people
are waiting. With no opening ahead it shows the title and the list only.

```json
"waitlist": { "title": "Be the first to know", "intro": "One message, the day times open.",
  "formUrl": "https://forms.gle/…", "message": "Hello Chalden, please tell me when the next pop-up opens." }
```

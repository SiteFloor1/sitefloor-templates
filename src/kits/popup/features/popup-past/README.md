# Past pop-ups (`popup-past`, Signature, page `past`)

Every stop whose last day has gone, latest first: the city, the place, the dates, the brand's own note and its own
photograph of it (`photo` on the stop; required on a client site once a stop has ended). Nothing is shown that the
brand didn't supply.

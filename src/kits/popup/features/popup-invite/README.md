# The invitation (`popup-invite`, Signature)

When a visitor picks a time in timed entry (`popup-slots`), a card appears: the brand, "You're invited", the day, the
time and the place, drawn on the phone in the look's own colours and type (1080 × 1350, saved as a PNG), with a
WhatsApp message to send to a friend ("Come with me to … (Not a ticket: book your own time on their site.)"). Nothing is
stored or sent anywhere by the site.

```json
"invite": { "title": "Bring someone" }
```

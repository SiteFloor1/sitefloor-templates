# Delivery and collection

| | |
|---|---|
| Feature id | `delivery` |
| Plan | starter and above |
| Config | `delivery`: `apps` (`name`: Deliveroo, Uber Eats, Just Eat or Our own delivery; `url`: the restaurant's own page on it), `collection?`; `sections.delivery` |
| Files | `delivery.njk`, `delivery.css` |

## How it works
Cards linking to the restaurant's pages on the delivery apps it uses, and to the takeaway page when `order` is on. No script.

# Dress code and etiquette

| | |
|---|---|
| Feature id | `dress-code` |
| Plan | plus and above |
| Config | `dressCode`: `summary`, `rules` (1–8 lines), optional `etiquette` (1–8 lines), `checked` (YYYY-MM-DD); `sections.dressCode` |
| Files | `dress-code.njk`, `.css` |

## How it works
A short card in the café's own words: the one-line code ("Smart, never stiff"), what isn't worn in the room, and any
etiquette worth knowing, with the date it was last checked. It answers "is there a dress code?" before anyone asks.

## When something is missing or fails
Static; no script.

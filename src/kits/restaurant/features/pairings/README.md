# What to drink with it

| | |
|---|---|
| Feature id | `pairings` |
| Plan | plus and above |
| Config | `pairs` on dishes (ids of drinks in a `drinks: true` section); `sections.pairings` |
| Files | `pairings.njk`, `pairings.css`, `pairings.js` |

## How it works
Pick a dish; see the drinks from the restaurant's own list that go with it, with prices and allergens. The menu and menu page also say "Goes with: …" under each paired dish. Without JavaScript every pairing shows.

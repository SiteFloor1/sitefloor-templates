# The gifts page

| | |
|---|---|
| Feature id | `gifts-page` (page `gifts`) |
| Plan | plus |
| Config | `giftsPage`: `kicker`, `title`, `intro?` |

## How it works
One page for giving: Give a sitting (Signature), gift vouchers (if on) and a link to the box from the pâtisserie
window (if on). A look can move those off the home page when this page is on (`look.json` → `onPages`).

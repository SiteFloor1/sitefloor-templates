# Bring a friend (GYM-11)

| | |
|---|---|
| Feature id | `gym-friend` |
| Plan | starter and above |
| Config | `friendPass`: `title`, `intro`, `rules` (the club's guest rules), `message` (the WhatsApp opening line) |
| Files | `gym-friend.njk`, `.js`, `.css` |

The friend's first name and a day in the next week go to the club on WhatsApp; the club replies. Nothing is stored.

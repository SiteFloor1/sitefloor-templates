# The club, room by room (GYM-6)

| | |
|---|---|
| Feature id | `gym-tour` |
| Plan | plus and above (a page: `club.html`) |
| Config | `tour` `{ title, intro, rooms: [{ id, name, photo, text, facts: [...] }] }` (two to eight rooms) |

A numbered index of the club's rooms beside one room at a time: its photograph large (3:2), what it's for and the facts
people ask (what's in it, how many, step-free, towels). The index is a tab list (arrow keys, Home and End); without
JavaScript it's a list of links down to each room, shown in turn, so nothing is lost and nothing moves when the
script starts. Photographs are the club's own (a
demo uses free licensed stock, credited).

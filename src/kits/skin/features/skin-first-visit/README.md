# First visit and patch tests (BEAU-2, Starter)

The clinic's paragraphs on a first visit (`firstVisit.sections`; the home page shows the first three) and its own
patch-test rule (`firstVisit.patch`: `hoursBefore`, usually 48, and the `line` the clinic writes). The visitor puts in
an appointment date; the page gives the day to come in for the patch test (on or before), to the calendar or to the
clinic. A past date, or one too soon for the rule, says so and offers no calendar file.

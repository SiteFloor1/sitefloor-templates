# Courses and memberships (BEAU-4, Plus)

`courses.courses`: a treatment from the menu (`item`), how many (`count`), weeks apart (`everyWeeks`), the clinic's
course `price` and `line`; the page shows the price one by one beside it, from the menu. `courses.memberships`: a
`name`, the `monthly` price, what a month `includes`, a `line`. With `skin-rhythm` on (Signature), the treatment
rhythm reminders sit beneath.

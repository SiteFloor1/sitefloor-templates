# fit-finder (lingerie kit, Plus)

What's wrong with the bra she wears now (the band rides up, the cup gaps, the straps dig, the wire sits on the breast…):
choose one and see what the shop's fitters say that usually means and what to ask at a fitting, with a WhatsApp line to
a fitter. It never gives a size; the note says so in the shop's words. Without JavaScript every answer shows.

```json
"fitFinder": { "note": "…", "problems": [{ "id": "band-rides", "label": "The band rides up at the back", "means": "…", "ask": "…" }] }
```
Heading: `sections.fitFinder`.

# lace-viewer (lingerie kit, Signature)

The lace, close: one large photograph of the shop's lace (its own macro photograph on a client site) with a round loupe
that follows the pointer or finger and magnifies by `zoom`; arrow keys move it, Escape hides it. Beside it, the shop's
notes on the lace (where it's made, how). Without JavaScript, the photograph and the notes. The photograph should be
at least twice the width it's shown at, so the loupe stays sharp.

```json
"lace": { "photo": { "src": "img/lace.webp", "width": 2400, "height": 1600, "alt": "…" }, "zoom": 2.5, "notes": ["…"] }
```
Heading: `sections.lace`.

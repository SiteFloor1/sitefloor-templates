# hint-sheet (lingerie kit, Plus)

Drop a hint: on any piece, a small sheet where she can add her size and a line of her own; *Send the hint* opens
WhatsApp with the piece, its price, her size (only if she typed it) and the link to it, and WhatsApp asks whom to send
it to. Nothing goes to the shop. The opening line defaults to the shop's own.

```json
"hint": { "note": "Thinking of something for me?" }
```
Message: `hintText` in `src/kits/lingerie/lib/pieces.js`. The same idea as the jeweller kit's hint.

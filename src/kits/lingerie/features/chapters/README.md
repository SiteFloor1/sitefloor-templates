# chapters (lingerie kit, Starter)

Chapter openers between home sections: one close crop full width (a strap, a hip, a lace edge), a few words very
large, one line (often the price) and a link. Each says which section it opens.

```json
"chapters": [{ "id": "slip", "before": "category-doors", "title": "Let it slip.", "line": "Halden silk, from £180.", "photo": { … }, "link": { "label": "The Halden collection", "page": "collection-halden" } }]
```
A link to a page whose feature is off is left out.

# collection-pages (lingerie kit, Signature)

A page for each collection (`collection-<id>`): its own small campaign of photographs edge to edge, its one line,
its colours as swatches, its story in the shop's words, every piece in it, and the other collections.

```json
"collections": [{ "id": "calloway", "name": "Calloway", "line": "…", "story": "…", "colours": […], "cover": { … }, "campaign": [{ … }, { … }] }]
```
Link to one from a chapter or the nav with `"page": "collection-calloway"`.

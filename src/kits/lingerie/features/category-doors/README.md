# category-doors (lingerie kit, Starter)

Shop by category: a tall photograph of a woman wearing each category, edge to edge. Tapping a door shows that
category's pieces just below (CSS `:target`, so it works without JavaScript); a category with no pieces listed offers
"Ask what's in" on WhatsApp. Swipe sideways on a phone.

```json
"categories": [{ "id": "bras", "label": "Bras", "photo": { "src": "img/door-bras.webp", "width": 720, "height": 1280, "alt": "…" } }]
```
Ids: bras, briefs, suspenders, bodies, nightwear, bridal, slips, robes, swim. Heading (optional): `sections.doors`.

# services (lingerie kit, Starter)

"Ask the shop": each service (a private fitting, bridal, personal shopping, a video fitting for online brands, the
size guide…) as one line and a short note; each opens WhatsApp with its own message. `modes` limits a service to
boutiques or online brands.

```json
"asks": [{ "id": "personal", "label": "Personal shopping", "line": "On WhatsApp, at whatever hour suits you", "message": "Hello Marese, I'd like some help choosing." }]
```
Heading: `sections.services`.

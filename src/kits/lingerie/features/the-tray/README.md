# the-tray (lingerie kit, Plus)

The tray: on any piece, *Have it at my fitting* puts it on her tray (three at most); a small chip says how many and
leads to the fitting request, which lists them in the WhatsApp message. Remembered on this phone only (local storage),
never sent anywhere else. Needs **private-fitting**. The same idea as the jeweller kit's tray; this markup is the
lingerie kit's own.

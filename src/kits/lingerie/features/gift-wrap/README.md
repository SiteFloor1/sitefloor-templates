# gift-wrap (lingerie kit, Starter)

How the shop wraps (its words), what wrapping costs (or that it's free), and the card written on the page, counted
to the shop's limit and sent on WhatsApp with the order.

```json
"giftWrap": { "text": "…", "price": 0, "cardMax": 160 }
```
Heading: `sections.wrap`.

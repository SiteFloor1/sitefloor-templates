# Planning and party walls (construction kit, Plus)

`planning.html`: planning permission, rear and side extensions, lofts, the lawful development certificate, party walls
and building regulations, for England, in plain words with each topic's GOV.UK pages and the date checked. The facts
live only in `lib/planning.js` (also used by the planning guide and the service pages); the builder adds their own
words on how they help (`help`). "A guide, not a decision" is stated first.


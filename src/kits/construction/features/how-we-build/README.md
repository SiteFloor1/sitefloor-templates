# How we build (construction kit, Plus)

`how-we-build.html`: each of `stages.items` in full (its `about`, its `weeks` from the builder's own jobs, a photograph),
then the builder's terms in their words (`howWeBuild.sections`: the contract, how payments work, the defects period,
living at home during the work). The total length shows only when every stage has `weeks`. On Signature the build in
3D sits between the stages and the terms.

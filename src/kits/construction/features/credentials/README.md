# Accreditations and insurance (construction kit, Starter)

From the builder's own certificates only: each membership or registration with its number and a link to the scheme's
public register, each insurance cover with its limit (and insurer if they like), the guarantee in their words, and the
month it was last checked. No logos. A demo is fictional: its numbers are all noughts, marked "(demo)", and it links to
no register.

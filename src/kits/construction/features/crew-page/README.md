# The team (construction kit, Signature)

`team.html`: the people a client will meet (project managers, the site manager, the joiner, the office), by name and
role, with one line in their own words and a portrait only if they want one.

```json
"crew": { "title": "The *team*", "intro": "…", "people": [{ "name": "…", "role": "Project manager", "line": "…", "photo": { … } }] }
```

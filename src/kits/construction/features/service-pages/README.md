# A page for each kind of work (construction kit, Signature)

One page per `buildTypes.items` entry, named by its id (extensions, basements, renovations, new builds, listed
buildings, interiors and joinery): the photograph wide, `about` (required here) and `includes` in the builder's words,
then up to four finished projects of that kind (`projects.items[].type`). One collection, counted as one page.

# What it costs (construction kit, Plus)

`costs.html`: costs explained honestly, in the builder's words: how they price, what decides the price, what is usually
paid to others (architect, engineer, party wall surveyor, building control), and VAT. The builder's own £ per m² rates
appear as a table only when `visualiser.rates` holds them; a demo says a real site would show them; a client without
published rates shows `noRates` in their words. No typical figures, ever.

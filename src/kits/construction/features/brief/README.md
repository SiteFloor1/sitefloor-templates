# Start a project (construction kit, Starter)

A short brief sent as one WhatsApp message: what (the builder's kinds of work, or something else), the postcode
district only (never the address), when, a budget band if the builder lists their own, and a few words. Without
scripts, a plain WhatsApp link with the builder's opening line. With the start page on (Plus), the look moves it there.

```json
"brief": { "title": "Start a *project*", "intro": "…", "opening": "Hello, I'd like to talk about a project.", "whens": ["As soon as possible", "In the next six months", "Next year"], "budgets": ["…"], "note": "…" }
```

`budgets` are the builder's own bands, or leave them out. Markup uses tokens only.

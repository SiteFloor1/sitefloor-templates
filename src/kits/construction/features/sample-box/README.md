# Sample box (construction kit, Plus)

On the specification page: the visitor ticks up to `max` of the builder's finishes (from `spec.items`), gives the
postcode district, and sends the list as one WhatsApp message; the builder brings or posts the samples. Without
scripts, a plain WhatsApp link.

```json
"sampleBox": { "title": "A box of *samples*", "intro": "…", "max": 6, "message": "Hello, could I see these samples?" }
```

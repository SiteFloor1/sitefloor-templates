# What we build (construction kit, Starter)

Each kind of work the builder takes on (extensions, basements, full renovations, new builds, listed buildings,
interiors and joinery) with a photograph and one line, as a ruled index. With service pages on (Signature) each row
opens its own page; with the services page on (Plus) the look moves the list there.

```json
"buildTypes": { "title": "What we *build*", "items": [{ "id": "extensions", "name": "Extensions", "line": "Rear, side and wrap-around, in brick, oak and glass.", "photo": { … }, "about": ["…"], "includes": ["…"] }] }
```

`about` and `includes` are for the service pages, in the builder's words. Markup uses tokens only.

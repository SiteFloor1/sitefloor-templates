# Projects page and a page for each project (construction kit, Plus)

`projects.html` lists every finished project (`projects.items`), and each has its own page named by its id (one
collection, counted as one page): the place and scope, the facts the builder gives (kind of work, year handed over,
weeks on site, postcode district), the first photograph large, the story in their words, the other photographs, and a
"before" photograph only where `consent` is true (the client agreed in writing). The look may move the reviews here.

# residences-quote: send this quote (Plus)

A "Send this quote" link in each home's detail opens `quote.html#<ref>-<stay>` (stay: nights, or `long`). The page
reads today's sheet, so the total is always today's, and says when the prices were updated and that it isn't a
booking. "Send it" opens WhatsApp to choose who gets it; "Copy the link" copies it. Unlisted: no sitemap, noindex.

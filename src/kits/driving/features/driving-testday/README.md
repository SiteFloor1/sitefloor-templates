# driving-testday (Starter)

"Test day, in order": the five parts of the car driving test and what to bring, written once in `lib/govuk.js` from
gov.uk ("What happens during the test") with the date it was checked, and the gov.uk links to apply for a provisional
licence, book the theory test and book the practical test. The instructor only sets the heading.

```json
"testDay": { "title": "Test day, in order", "intro": "What happens, from gov.uk." }
```

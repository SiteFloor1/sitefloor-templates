# driving-instructors

Instructors (`instructors.html`): each instructor, the gearboxes they teach and their DVSA status: "ADI" (approved driving instructor) or "PDI" (trainee). `badge` only as the client gives it, ADIs only, never on a demo. `passRate` only on client sites, with the dates it covers. Settings: `site.instructors` (see config.js for every key).

# driving-progress

Learner progress (`progress.html`): the learner types the code their instructor gave them and sees each skill at the DVSA's five levels, the last lesson, what was covered and what to practise. From the instructor's sheet, keyed by code, no names; a sheet older than `staleAfterHours` (default 336, two weeks) shows nothing. Settings: `site.progress` (see config.js for every key).

# Class types (PIL-2)

| | |
|---|---|
| Feature id | `class-types` |
| Plan | starter and above |
| Config | `classTypes.items`: `{ id, name, minutes, level?, text }`; `sections.classTypes` |
| Files | `class-types.njk`, `.css` |

## How it works
Every class the studio runs, with its length, level and one line in the studio's words. The timetable names classes
by these ids.

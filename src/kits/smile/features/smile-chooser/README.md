# Tell me what you'd change (home, Plus)

The clinician's own line (`quote`, in their voice), signed with their register line; tapping a choice writes the message to the studio in the bubble and the Send link (WhatsApp or the studio's booking channel). Nothing clinical is asked; `note` tells people not to send photos of their teeth. Without JavaScript the first message is ready in the link.

```json
"chooser": { "quote", "by": "<clinician id>", "photo": { "src", "width", "height", "alt" }, "note", "options": [{ "label": "A chipped tooth", "message": "Hi …" }] }
```

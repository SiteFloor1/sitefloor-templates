# Aftercare (Plus)

The clinician's own instructions and `urgent` (who to call if something feels wrong, out of hours). Plus extra: reminders, each `months` after the day of treatment, added to the patient's calendar.

```json
"aftercare": { "title", "intro", "urgent": "…", "sections": [{ "heading", "text" }], "reminders": [{ "id": "top-up", "label": "Whitening top-up", "months": 6, "note": "…" }] }
```

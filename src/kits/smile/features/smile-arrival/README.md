# Arriving (Signature)

Choose the appointment time and the way from the door to the chair re-times itself (`at`: minutes from the appointment). Without JavaScript it shows for `start`.

```json
"arrival": { "title", "intro", "times": ["08:15", "12:40", "18:00"], "start": "08:15", "photo": { … }, "steps": [{ "at": -2, "text": "The blue door on Calvert Yard.", "note": "Ring once." }] }
```

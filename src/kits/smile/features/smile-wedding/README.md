# When's the big day (Signature)

On the home page (a section) and its own page: one date in, every step dated, worked back from the studio's own `weeksBefore`; past steps marked "Now"; the dates to the calendar or to the studio. Uses the shared src/core/lib/diary.js.

```json
"wedding": { "title", "intro", "late": "…", "message": "Hi …, here are my dates.", "steps": [{ "id": "consult", "label": "Consultation", "weeksBefore": 12, "note": "…" }] }
```

# Shot list builder (CVID-2)

| | |
|---|---|
| Feature id | `carfilm-shotlist` |
| Plan | plus and above |
| Config | `shotList` { title, intro, message (with {shots}), items [{ id, label, photo { src, width, height }, on? }] } |

# Delivery formats (CVID-7)

| | |
|---|---|
| Feature id | `carfilm-formats` |
| Plan | signature |
| Config | `formats.items` [{ id, name, ratio ("2.39:1"), size ("3840 × 1608"), use, viewfinder? }], `formats.note?` |

The viewfinder's format switch: 2–5 formats marked `viewfinder: true` snap the frame to their shape; drag it, or the
arrow keys, to reframe. A size must match its shape (checked). The Deliveries guide page lists every format with its
size and use. The sizes are the studio's own; the demo's are labelled samples.

# Golden-hour planner (CVID-5)

| | |
|---|---|
| Feature id | `carfilm-planner` (page `golden-hour`) |
| Plan | signature |
| Config | `planner` { title, intro, message ({road} {date} {gold} {sunset}) }; `roads` |

Any of the studio's roads and any date: golden hour, sunset and blue hour, calculated, and the day drawn as a band of
light (night, blue hour, golden hour, low sun, day: the look's colours). Hold this light sends it on WhatsApp. Shares
the plan with the share card.

# ifa-advisers (IFA-1, Starter)

The advisers on the home page, each with their FCA individual reference number linked to the register (their own entry
on a client site when `registerUrl` is given; the register's search otherwise). Demo numbers end in 00000.

```json
"advisers": { "items": [{ "id": "…", "name": "…", "role": "…", "irn": "ABC01234", "registerUrl": "https://register.fca.org.uk/s/individual?id=…", "letters": "Chartered Financial Planner", "line": "…", "photo": { … } }] }
```

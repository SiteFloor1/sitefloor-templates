# ifa-upload (IFA-8, Plus)

On the first-meeting page: a link to the firm's own secure portal or upload service, and the line not to email
statements. Nothing is hosted by Sitefloor; the website never receives a file.

```json
"upload": { "url": "https://…", "name": "our secure portal", "line": "Upload them through our portal; we'll see them before we meet." }
```

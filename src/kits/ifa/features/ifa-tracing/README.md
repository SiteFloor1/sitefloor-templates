# ifa-tracing (IFA-11, Signature)

`old-pensions.html`: the visitor lists old employers and personal pensions; the page builds a tracing list to copy or
print, with the government's free Pension Tracing Service and what to ask each scheme (`lib/tracing.js`, checked 16 Nov
2026). Everything stays in the browser: nothing is stored, sent or searched, and it never claims to find a pension.

```json
"tracing": { "title": "Old pensions", "intro": "…" }
```

# ifa-independence (IFA-7, Starter, always on)

Whether the firm's advice is independent or restricted, said plainly (COBS 6.2B), and `independent.html` (free on every
plan) explaining the difference and pointing to free guidance (MoneyHelper, Pension Wise).

```json
"independence": { "status": "independent", "line": "Our advice is independent: we can recommend from the whole market.", "body": ["…"] }
```
Restricted firms add `"restrictedTo"` (what their advice covers); a restricted firm's line can't call itself independent.

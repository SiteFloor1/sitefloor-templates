# ifa-year (IFA-9, Plus)

`your-year.html`: the firm's review rhythm (first plan, yearly review, what brings an extra meeting, what happens if an
adviser leaves) and a yearly reminder for the client's chosen month as a calendar file (`lib/year.js`), made in the
browser; nothing is sent.

```json
"year": { "intro": "…", "steps": [{ "when": "Within a month", "what": "…" }], "note": "…", "adviserLeaves": "…" }
```

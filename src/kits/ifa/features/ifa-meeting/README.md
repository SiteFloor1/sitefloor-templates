# ifa-meeting (IFA-3, Plus)

`first-meeting.html`: free, how long, where, what happens after, booking through the firm's own channel (`booking`), and
a checklist of what to bring. Ticks are kept in this browser only (`localStorage`, when allowed); nothing is sent.

```json
"meeting": { "title": "Your first hour is free", "intro": "…", "length": "An hour", "where": ["…"], "after": "…", "bring": ["…"] }
```
The site's questions (shared `questions`) follow on this page.

# hol-homes: the homes we look after (HOL-7, Plus page)

`homes.title`, `homes.intro`, `homes.items` (each { id, name, town, sleeps, bedrooms, line, photo, stay, book }). The
price shown is always the guest's TOTAL for a stated stay (`stay.nights`, `stay.total`, `stay.when`) with every
mandatory fee included, never a nightly rate with fees added later (CMA). Three on the home page, all on The homes,
each with its booking link (the listing or the company's booking page). On Signature, `hol-calendar` adds each home's
next free dates.

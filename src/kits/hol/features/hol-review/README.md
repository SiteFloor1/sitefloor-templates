# hol-review: ask for a revenue review (HOL-3, Plus page)

`review.title`, `review.intro`, `review.message` (the company's opening line) and `review.now` (how a home can be let
today: "Not let yet", "On Airbnb myself"…). The answers are written into one WhatsApp message (lib/owners.js
`reviewText`) that the owner sends; the site sends and keeps nothing. No figure is worked out here: the company
replies after a visit.

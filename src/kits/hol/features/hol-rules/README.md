# hol-rules: rules where your home is (HOL-2, Starter, free page)

The regions and their rules live in `lib/rules.js` (England, London, Scotland, Wales), each line with its official
link (GOV.UK, legislation.gov.uk, gov.scot, GOV.WALES), its source and the date it was checked. A site only chooses
which region opens first (`rules.region`). Six months after a line was checked it stops being shown as current: the
site shows "due a fresh check" and the official link instead, until someone checks it and updates the date. The kit
never paraphrases a rule as advice. Home card with region buttons (one script, no data), and the rules page in full.

# hol-turnover: between guests (HOL-5, Plus, home page)

`turnover.title`, `intro`, `note` and `steps` (each { time, title, detail, photo }); times are real clock times in
order (refused otherwise). The company's own photographs of each step on a client site. Choosing a time opens its
line and fades to its photograph (0.7s, only on a tap, never on scroll). Without JavaScript every line is open. The
cleaning and linen page (Signature) shows the same day in full.

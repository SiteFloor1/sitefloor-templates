# events-journal (Plus)

The journal (`journal.html`) and a page per article (`article-<id>.html`): the agency's own writing (planning
timelines, choosing a venue, what a tasting is for). `journal.items`: `{ id, title, date, intro, body }`, `body` a list
of paragraphs (`*em*` and `[link](url)` markup). The articles count as one page.

# events-occasions (Plus)

A page per occasion or service, at `<id>.html` (weddings, companies, private-parties, launches, design-and-styling,
production, destination): the photograph, the title and line, the agency's paragraphs, up to three rooms of the
matching occasion (`rooms`: wedding, corporate, private, launch, other) and Begin a brief. The pages count as one.
Add them to `nav` as `{ "label": "Weddings", "page": "weddings", "feature": "events-occasions" }`.

# events-key-dates (Plus)

On Start your event: the agency's milestones (`keyDates.items`: `{ label, weeksBefore }`, e.g. final guest numbers
three weeks before) worked back from the date chosen in the brief, the past ones left out, listed and saved as one
calendar file (all-day events; works with Apple, Google and Outlook calendars). Made in the browser; nothing is sent.

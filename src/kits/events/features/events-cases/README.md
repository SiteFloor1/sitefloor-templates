# events-cases (Signature)

Case studies (`case-studies.html` and `case-<id>.html`, EVT-5): events the agency produced, each with `title`,
`occasion`, `guests`, `when` ("Winter", "June 2026"), a `line`, the `brief`, the `room` and the `mood` in the agency's
own words (materials and colours named, not swatches), and the photographs of that event. Client names only with the
client's written permission; never a design visual (`config.js` refuses one). The case studies count as one page.

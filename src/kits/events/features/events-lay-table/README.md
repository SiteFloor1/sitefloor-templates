# events-lay-table (Signature)

Lay the table: three dressings of one table from one camera (for example: candlelight; candlelight and greenery;
candlelight, greenery and flowers), to choose between. Opens on the third. Always labelled "A design visual". The three
pictures must share one size (one camera). `layTable.dressings`: exactly three `{ label, line, photo }`.

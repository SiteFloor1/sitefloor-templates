# Corporate B2B kit (`corp`)

For regional UK B2B firms: precision engineering and manufacturing, IT managed services, logistics, consultancy.
Plan, features per tier and honesty rules: `docs/trades/corporate/playbook.md`. Buyer questions:
`docs/trades/corporate/questions.md`. Not built yet: the design (Title block, demo Keswold) is waiting for approval.

## Photographs of the client's work
- **Photo labels and dimensions must come from the client's own part.** The leader labels on a photograph
  (material, finish, thread, feature) and any dimension or tolerance shown on it are copied from that part's drawing,
  supplied by the client, and the photograph must be of that same part. Never label a stock or demo photograph with
  figures a client could be held to, and never reuse one part's labels on another part's photo.
- Tap-to-measure (a dimension drawn where you point) is a client-only Signature option for the same reason: it needs the
  client's own photograph and figures, so it is off the demo.

## Live title-block cells
Prototype lead time, production lead time and next free machine time each come from the firm's published Sheet (a value
and an updated time per row). Each shows "updated <date>"; a row older than 7 days, or with no updated time, shows as
old and asks the buyer to get in touch for today's figure. Never shown as current when it isn't.

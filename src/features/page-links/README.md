# Page links

| | |
|---|---|
| Feature id | `page-links` |
| Plan | plus and above |
| Config | `pageLinks` (`page`, `image`, `kicker`, `title`, `cta`) |
| Files | `page-links.njk`, `page-links.css` |

## How it works
Large photo cards linking to inner pages. Links to pages that are not enabled are dropped automatically.

## When something is missing or fails
—

Registered in `src/features/registry.js`. Add to a site by listing the id in `features` in its `site.json`.
